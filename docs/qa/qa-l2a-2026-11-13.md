## 4. Environnement et observations

- Le cluster local `/var/tmp/qavisv1` est en `SQL_ASCII` : `char_length` compte des octets, donc un texte accentué de « 500 caractères » dépasse la limite ici (Neon est en UTF8). Les textes de test de la migration sont dimensionnés en octets.
- Le cluster, les ports et les noms de base sont partagés entre agents : un autre agent exécutait en même temps `QA-visibility-v4bis` (base `grc_qa_vv4bt`, port 8096, aussi utilisé par QA-Import et V2). Résultat : 24 rouges factices sur V4bis ; avec base `grc_qa_l2avb` et port 8118 (copie temporaire du fichier, supprimée) : 27/27 PASS. - `QA-panel-migrations` live (compteur de permissions `users` 0 contre 1, signalé par A06) : non reproduit sur une base fraîche issue de `qa-visibility-v1-setup.sh` (3 fichiers, 80 PASS, 21 ignorés par construction) ; le rouge vient d'un état de base modifié par d'autres suites, pas du lot (le fichier ne dépend pas de 096 pour ce compteur).
